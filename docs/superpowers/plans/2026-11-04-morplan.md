# MorPlan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Thai-language CMU timetable planner (drag-and-drop calendar, clash warnings, plans, share, export) plus a measured Thai RAG over public regulations.

**Architecture:** Pure TypeScript domain core (`src/lib/core`) used by a client-heavy Next.js planner; workspace state in browser storage, synced to Supabase Postgres when signed in. RAG corpus OCR'd once by a Dockerised Python step into committed `data/pages.jsonl`; chunking, BM25, dense and hybrid retrieval are TS modules shared by the app and the eval script.

**Tech Stack:** Next.js 16.4 (cacheComponents off), React 19.3, TS, Tailwind 4, @dnd-kit/core, Supabase (auth + Postgres + pgvector), Drizzle, zod, @huggingface/transformers (multilingual-e5-small), Gemini REST, Vitest + fast-check, Playwright, Tesseract in Docker.

**Spec:** `docs/superpowers/specs/2026-11-04-morplan-design.md`

## Global Constraints

- Never ask for or accept reg credentials; no field labelled username/password for reg anywhere.
- Header or footer on every page: "ไม่ใช่ระบบทางการของ มช."; no CMU logo.
- Every rule answer ends with "ตรวจสอบกับประกาศทางการอีกครั้ง"; unanswerable → "ไม่พบ".
- Imported sections stay per user/browser; never pooled into a shared catalogue.
- Scraping: only the public exam timetable, cached in `data/exams/<term>.json`, ≥2 s between requests, custom User-Agent.
- Dev server port 3100; Supabase ports 553xx.
- UI copy Thai; code, comments and docs English.

## Review Focus

1. Pasted reg text with odd whitespace/line breaks → sections still parse, or a warning says which line failed (parser tests with messy fixture).
2. Classes that touch end-to-start (0930/0930) → no clash (property + example test).
3. Course with lecture and lab meetings in different patterns → both meetings placed and both checked (conflict test).
4. Browser storage unavailable/corrupt JSON → planner starts with an empty workspace instead of crashing (storage test).
5. Question with no supporting passage (e.g. about dormitory fees) → "ไม่พบ", not a hallucinated answer (abstention eval + unit test with fake LLM).

### Task 1: Domain core — time, day patterns, conflicts
**Files:** `src/lib/core/{types,time,conflicts}.ts`, tests `src/lib/core/{time,conflicts}.test.ts`
**Produces:** `parseDays(p: string): Day[]`, `parseTimeRange("0800-0930"): {start,end}|null`, `fmtTime(min): "08:00"`, `findConflicts(sections: Section[]): Conflict[]` where `Conflict = {kind:"time"|"midterm"|"final"|"duplicate", a: string, b: string, day?: Day, overlap?: {start,end}}`.
- [ ] Tests: every pattern in the reg form list (`Su Mo Tu We Th Fr Sa MWF TT M-F M-Sa M-Su MW WF MTu TuW WTh ThF MF MTT MTuW MWTh MTuWF M-Th TuWTh MTuThF TTF MWThF TuF FSa Tu-F WThF MTh TuSa TuWF SaSu MSu FSu MTuTh`) maps to the right days; `TT`→Tu,Th; `TBA`→[]. Conflicts: overlap detected with exact overlap window; touching not a clash; exam clash only when same date and overlapping time; property test: `findConflicts` symmetric and never reports a section against itself.
- [ ] Implement, run `npx vitest run src/lib/core`, commit.
